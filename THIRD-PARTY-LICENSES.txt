Both libraries are built from the upstream release tags by vcpkg
(https://github.com/microsoft/vcpkg, ports "libheif" and "libde265"). vcpkg applies
small build-system/export patches, found in ports/libheif and ports/libde265 of the
vcpkg revision pinned in vcpkg.json. libheif is built WITHOUT the x265 encoder
and without any other optional codec.

LGPL notice: heic_thumbnail.dll uses these libraries only through their public C API
and loads them as separate DLLs at runtime. You may replace heif.dll / libde265.dll
with your own compatible (modified) builds. The complete corresponding source code is
available at the URLs above; each GitHub release of HEIC Explorer Preview additionally
attaches the exact source archives and vcpkg port files used for that build.
